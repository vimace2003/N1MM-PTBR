Advanced Topics

Operating Modes

  • SO1V: Single Operator 1 VFO — operação com 1 rádio, 1 banda
  • SO2V: Single Operator 2 VFO — 2 bandas simultaneamente via F7
  • SO2R: Single Operator 2 Radios — 2 rádios diferentes
  • Multi-Operator: Vários operadores, 1 log compartilhado

SO2V Operating Tips

  • Configure VFO A (running) e VFO B (S&P) em bandas diferentes
  • Use F7 para alternar entre VFOs rapidamente
  • Mantenha volume separado para cada VFO se possível
  • Pratique muito antes do contest! SO2V é skill que requer training

Multi-Operator Setup

  • Multiplos PCs/operadores conectados via network
  • 1 database central compartilhado
  • Sincronização automática de QSOs entre estações
  • Merge final de logs ao fim do contest

DX Cluster & Spotting

  • Integração com DX Cluster (telnet)
  • Receber spots de outros operadores em tempo real
  • Spots aparecem no Bandmap automaticamente
  • Aumenta eficiência em contest de DX

Rotor Control

  • Controle de rotor de antena via serial port
  • Suporta Yaesu GS-232, Idiom Press, etc.
  • Useful para direcionamento em VHF/UHF
  • Automático basado em bearing do QSO
