Manual N1MM+ em Português

Perguntas Frequentes (FAQ)

Instalação e Setup

P: Preciso instalar N1MM+ em todas as máquinas?
R: Não. Você pode usar uma instalação central e acessar de máquinas da rede via network share.
P: Como faço backup do meu banco de dados de contests?
R: Use File > Backup Contest Database. Recomenda-se fazer backup antes de cada contest importante.
P: Qual é a melhor configuração de radio?
R: Depende do seu radio. Consulte o manual do N1MM+ para configurações específicas de cada modelo.

Durante o Contest

P: Perdi um QSO. Como faço para recuperar?
R: Use Ctrl+Z para desfazer ou abra a Log Window e delete o QSO incorreto.
P: Como funciona a duplicata (Dupe)?
R: Um QSO é considerado dupe quando você já contatou a mesma estação na mesma banda, mesmo modo.
P: Posso usar dois VFOs simultaneamente (SO2V)?
R: Sim! Use F7 para ativar VFO2. Isso permite trabalhar duas frequências/bandas ao mesmo tempo.
P: Como editar um QSO depois de enviado?
R: Clique duplo na entrada na Log Window, edite os campos e clique OK.

Exportação e Submission

P: Como export para Cabrillo?
R: Use File > Export Cabrillo. O arquivo será gerado no formato padrão para submission.
P: Posso editar o arquivo Cabrillo antes de enviar?
R: Sim, o Cabrillo é um arquivo texto. Mas certifique-se que o formato permaneça correto.

Troubleshooting

P: N1MM+ não conecta no radio. O que fazer?
R: Verifique: (1) Cabo CAT conectado; (2) Porta COM correta em Configurer; (3) Baud rate compatível.
P: Alguns QSOs estão com pontuação zero. Por quê?
R: Verifique a Exchange. Se inválida ou incompleta, o QSO pode não ser pontuado corretamente.
