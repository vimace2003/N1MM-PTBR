Before the Contest

Preparação essencial para operar um contest com sucesso.

1-2 Weeks Before

  • Revise as regras completas do contest
  • Configure o contest no N1MM+ (ou import UDC se custom)
  • Teste sua estação: radio, keyer, interface, áudio
  • Atualize master.scp e dados de call history
  • Prepare Function Keys com macros de CW/SSB/RTTY

Day Before Contest

  • Faça backup do database de contests
  • Teste CAT control, PTT, CW, áudio
  • Verifique conexão de rede (se multi-computer)
  • Sincronize relógio do PC com internet (NTP)
  • Teste Internet para DX Cluster (se usar)
  • Limpe buffer de dupes (Clear Dupes) se necessário

Contest Morning Checklist

  • ✓ Startup completo: radio, interface, PC
  • ✓ Teste rápido: digitar call, verificar Check Window
  • ✓ Teste CW: envie alguns dits para verificar sidetone
  • ✓ Verifique bandas: frequências abertas, condições
  • ✓ Confirme indicativo e categoria corretos
  • ✓ Valide primeira exchange (send test QSO)
  • ✓ Reset score/timer se novo contest

Last Minute

  • Sincronize relógio NTP (importante para RTTY/Digital)
  • Verifique Internet/Email para regras de último minuto
  • Teste monitoramento: amplifier funcionando?
  • Confirme antena e PTT ligados
  • Respire fundo! Boa sorte! 📻
