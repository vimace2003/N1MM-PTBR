Log Editing and Merging

Edição de logs e merge de múltiplos logs de operadores.

Editing QSOs

Editar um QSO Individual

  • Abra Log Window
  • Clique duplo no QSO para editar
  • Modifique fields conforme necessário
  • Clique OK
  • Score automático é recalculado

Delete QSO

  • Selecione QSO na Log Window
  • Pressione Ctrl+D ou Delete
  • Confirme exclusão

Duplicate a QSO

  • Útil se cometeu engano e quer rebotar
  • Selecione QSO, Ctrl+Alt+P para duplicar
  • Edite a cópia conforme necessário

Merging Logs

Quando múltiplos operadores usam máquinas diferentes em multi-operator:

Merge Process

  1. Certifique-se que todos os operadores fizeram backup (File > Backup)
  2. Exporte logs de cada PC para Cabrillo ou .log
  3. No PC master: File > Merge logs
  4. Selecione logs para mesclar
  5. N1MM+ detecta dupes automaticamente
  6. Revise conflitos e resolva manualmente se necessário

Log Validation

Antes de submeter para o contest:

  • Rescore: Ctrl+R para recalcular pontuação
  • Check Exchange: Valide formato de exchange
  • Verify Dupes: Procure por QSOs duplicados
  • Count: Confirme número de QSOs esperado

Export para Submission

Cabrillo Format

  • Formato padrão para maioria de contests
  • File > Export Cabrillo
  • Selecione arquivo de destino
  • Email para contest organizer

Native .LOG Format

  • Alguns contests aceitam .LOG do N1MM+
  • File > Export N1MM+ Log

After Submission

  • Mantenha cópia do arquivo exportado
  • Guarde email de confirmação
  • Acompanhe publicação de resultados
  • Se houver erro, contate contest director
