Logging QSOs

Métodos e técnicas para logar QSOs eficientemente durante um contest.

Basic Entry Method

  1. Sintonize uma frequência
  2. Ouça o call
  3. Digite o call na Entry Window
  4. Aguarde a Check Window confirmar
  5. Digite a exchange recebida
  6. Pressione Tab ou Enter para guardar

Fast Entry Method

  • Rápido para operadores experientes
  • Use Tab para mudar entre campos (Call → Exchange)
  • Enter automático envia QSO (se ESM mode ativo)
  • Velocidade: 1 QSO a cada 5-10 segundos é possível

CW Operation

  • Calling: Sintonize alguém chamando, responda
  • Running: Transmita CQ, estações respondem
  • Search and Pounce: Procure calls na banda, responda
  • Two-radio (SO2V): VFO1 para calling, VFO2 para running

Exchange Tips

  • Ouça completo antes de digitar (não se apresse)
  • Confirme números: "5-9-5" = 595 (cinco-nove-cinco, não cinco-noventa-cinco)
  • Serial numbers: podem ser 001-999 tipicamente
  • Gridsquares: 4 ou 6 caracteres, ex: GG52, GG52XB
  • States/provinces: use abreviações padrão (MA, ON, etc.)

Dupe Checking

  • Check Window mostra se é dupe automaticamente
  • Se dupe: exchange fica vermelha (cor customizável)
  • Você pode logar dupes (serão descartados na pontuação)
  • Muitos prefere não logar dupes para economizar tempo
