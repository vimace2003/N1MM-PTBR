Radio Control

Aba essencial para configurar o seu radio (Yaesu, Icom, Kenwood, Elecraft, etc.) e comunicação CAT.

Configuração Básica

  • Radio Type: Selecione o modelo do seu radio
  • COM Port: Porta onde o radio está conectado (COM1, COM2, USB, etc.)
  • Baud Rate: Velocidade de comunicação (normalmente 4800 ou 9600)
  • Data Bits: Geralmente 8
  • Stop Bits: Geralmente 1 ou 2
  • Parity: None (nenhum) é mais comum

VFO Configuration

  • Main VFO: Frequência principal de operação
  • VFO B (SO2V): Segundo VFO para operação em duas bandas simultaneamente
  • Band Selection: Seleção de bandas (160m, 80m, 40m, 20m, etc.)
  • Mode Select: CW, SSB, RTTY, AM, FM

Teste de Conexão

Clique em Test para verificar se a comunicação CAT está funcionando. Se OK, o radio responde imediatamente.

Problemas Comuns

  • Porta não aparece: Verifique conexão USB ou serial, drivers instalados
  • Baud rate mismatch: Radio e software devem usar mesma velocidade
  • Parity error: Confirme configuração no manual do radio
