PTT and Voice Output

Configuração de Push-to-Talk (PTT), transmissão de voz e áudio para modos digitais.

PTT Methods (Métodos de PTT)

CAT PTT (via radio)

  • N1MM+ envia comando PTT via CAT para o radio
  • Mais simples: não precisa de hardware extra
  • Funciona com radios que suportam PTT via CAT

Serial DTR/RTS (via porta serial)

  • Usa pinos DTR ou RTS da porta serial/USB
  • Conecta a 1 pino de entrada do amplifier ou interface
  • Método tradicional ainda muito usado

LPT Port (paralela)

  • Raro em computadores modernos
  • Usava porta paralela do PC

Footswitch/Manual

  • Footswitch ou botão para ativar PTT manualmente
  • Quando ESM mode está ativo

Voice Output

  • Voice Device: Selecione saída de áudio (speakers, line out)
  • Microphone Input: Entrada para monitoramento local
  • Text-to-Speech: Sintetizar voz para callsigns/exchange
  • CQ Message: Mensagem de CQ em voz

Conexão Física

Típico para SSB em contest:

  • Áudio da placa de som → microfone do radio
  • PTT → pino DTR/RTS via interface
  • Headphone radio → entrada de áudio do PC
