Digital Modes Configuration

Configuração de modos digitais: RTTY, PSK31, JT modes (FT8, MSK144), etc.

Digital Interface Methods

Audio Interface (Soundcard)

  • Áudio sai do PC → entrada de áudio do radio
  • Áudio recebido → entrada do PC
  • Funciona com qualquer programa de modo digital
  • Requer interface de áudio com isolamento

USB Interface (ex: MicroHAM, SignaLink, RigBlaster)

  • Todos os sinais passam por interface USB
  • Isolamento elétrico built-in
  • Mais confiável e profissional
  • Suporte integrado no N1MM+

Native USB Radio (IC-705, IC-9700)

  • Radio com USB integrado
  • Áudio digital via USB, sem interface extra
  • Muito simples de configurar

RTTY Setup

  • Bauds: 45.45 ou 75 baud (45.45 mais comum em HF)
  • Shift: 170 Hz (padrão) ou 200 Hz
  • Mode: USB ou LSB conforme o contest
  • Software: N1MM+ pode usar MMTTY, fldigi, ou outros

FT8 Setup (via WSJT-X)

  • N1MM+ se integra com WSJT-X para FT8
  • Audio route: PC soundcard → radio → antena
  • Suporte para automação de contests FT8
  • Timing crítico: sincronize o relógio do PC

Common Issues

  • No audio: Verifique mixer levels, drivers de áudio
  • Overmodulation: Reduza level de áudio saindo do PC
  • Undermodulation: Aumente level de entrada do radio
  • Latency: Use interface dedicada para reduzir atraso
