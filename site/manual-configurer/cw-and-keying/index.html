CW and Keying

Configuração de CW (Morse), keying, keyer externo e Winkeyer.

Keying Methods

CW Keying via CAT

  • N1MM+ envia Morse diretamente via CAT para o radio
  • Radio é responsável por gerar o CW
  • Mais simples, não precisa hardware extra

Serial Port Keying

  • Usa pinos da porta serial para controlar keyer
  • Métodos: DTR/RTS ou hardware serial-to-keyer
  • Compatível com keyers tradicionais

Winkeyer USB

  • Hardware dedicado: Winkeyer da K1EL
  • Conexão USB, suporte nativo no N1MM+
  • Controle fino: speed, weight, spacing
  • Monitoramento de CW via sidetone

MicroHAM Keyer

  • Interface multi-propósito com keyer integrado
  • Suporte via serial ou USB

CW Parameters

  • Speed (WPM): Palavras por minuto (típico: 25-40 em contest)
  • Weight: Proporção de espaço vs ponto (Mark/Space ratio)
  • Sidetone Frequency: Frequência do monitoramento (típico: 600-800 Hz)
  • Sidetone Level: Volume do monitoramento
  • QSK (Break-in): Capacidade de receber enquanto transmite

Configuration Tips

  • Teste o keying antes do contest para garantir funcionamento
  • Use sidetone para verificar fidelidade do CW
  • Configure speed confortável (mais rápido = mais difícil para tuning)
  • Personalize macros de CW via Function Keys
