Ports and CAT (Computer-Aided Transceiver)

CAT permite que o N1MM Logger+ controle seu radio: frequência, modo, VFO, banda, etc.

Tipos de Conexão

Serial Port (COM)

  • Porta serial RS-232 tradicional (D-SUB 9-pin)
  • Velocidade típica: 4800 ou 9600 baud
  • Comprimento máximo do cabo: ~15m

USB-Serial Adapter

  • Converte USB em serial virtual (COM port)
  • Chips comum: FTDI, CH340
  • Drivers precisam estar instalados

Native USB (alguns radios modernos)

  • Radio conecta direto via USB (ex: Icom IC-705)
  • Emula porta serial virtual automaticamente
  • Geralmente mais rápido e confiável

Detecção de Portas

N1MM+ detecta automaticamente portas COM disponíveis. Se não aparecer a sua:

  • Desconecte e reconecte o cabo
  • Reinicie o programa
  • Verifique Device Manager do Windows para confirmar porta
  • Instale drivers do adapter USB se necessário

CAT Protocols

  • Icom CI-V: Protocolo padrão Icom, 9600 baud
  • Yaesu SCU: Protocolo Yaesu
  • Kenwood: Protocol Kenwood para TS series
  • Elecraft K3: Serial a 38400 baud
