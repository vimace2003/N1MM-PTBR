Yaesu Radio Setup

Popular Models

  • FTDX101D: Flagship HF premium
  • FTDX5000: Dual VFO HF
  • FT991A: Compact HF/50MHz
  • FT897D: Portable HF/VHF/UHF QRP

CAT Setup

  • Protocol: Yaesu SCU (Serial Command Unit)
  • Baud Rate: 4800 ou 9600
  • Connection: Serial COM port (USB possível)
  • Data Bits: 8
  • Stop Bits: 2

N1MM+ Configuration

  • Configurer → Radio Control → Select "Yaesu"
  • Choose correct model (FTDX101, FT991A, etc.)
  • Set COM port e Baud Rate (4800 típico)
  • Test para verificar comunicação

Tips

  • Alguns modelos Yaesu usam 4800 baud por default
  • Verifique manual do radio para confirm
  • USB connection funciona bem com drivers corretos
