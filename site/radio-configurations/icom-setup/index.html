Icom Radio Setup

Popular Models

  • IC-7610: Transceiver HF/50MHz premium
  • IC-7850/7851: Flagship HF, dual receive
  • IC-7300: Compact HF mid-range
  • IC-705: Portable QRP HF+VHF/UHF
  • IC-9700: VHF/UHF/23cm all-mode

CAT Setup

  • Protocol: CI-V (Icom standard)
  • Baud Rate: 9600 (padrão), 19200 disponível
  • CI-V Address: Verificar manual do radio (default: 7E)
  • Connection: Serial COM port ou USB

N1MM+ Configuration

  • Configurer → Radio Control → Select "Icom CI-V"
  • Choose COM port (ou USB virtual port)
  • Set Baud Rate: 9600
  • Click Test para verificar

Notes

  • Icom suporta CAT via serial e via USB nativo
  • CI-V protocol é padrão para quase todos modelos
  • Verifique CI-V Address no menu do radio se tiver problemas
