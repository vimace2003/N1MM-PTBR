Setup UHF and VHF Contests

Setup VHF and Up Contests – CW and SSB

Em contests VHF e acima, é a norma fornecer relatórios de sinal precisos. Use Tab para ir do campo call sign para os campos de relatório de sinal. Você notará que realça a força para permitir modificação rápida.

Logging Digital Mode Contacts

N1MM+ oferece suporte a alguns modos digitais: RTTY, PSK31 e PSK63 via janela Digital Interface. Modos "JT" como FT8, MSK144, FT4, etc. são suportados via interface WSJT-to-N1MM+ descrita no manual. Lembre-se de definir Mode category como SSB+CW+DIGITAL no Contest Setup dialog para habilitar pontuação de modos digitais.

ARRL 10GHz and Up

  • Log Type: ARRL10GHZ
  • Sent Exchange: Your six character grid (Example: JO33ab)
  • Estações são encorajadas a operar de mais de um local único, referido como "Rover"
  • O contest ocorre em dois finais de semana em agosto e setembro
  • Use o mesmo log para ambos os finais de semana para garantir pontuação e rastreamento de DUPE apropriados

ARRL222 and Up August UHF Contest

  • Log Type: ARRL-222
  • Sent Exchange: Your six character grid (Example: JO33ab)
  • Exchange de relatório de sinal é opcional
  • Estações podem ser registradas mais de uma vez de um grid diferente sem ser um dupe (para estações Rover)

ARRL VHF Contests

ARRL January VHF Sweepstakes: Log Type: ARRLVHFJAN | Exchange: four character grid (Example: JO33)

ARRL June VHF QSO Party: Log Type: ARRLVHFJUN | Exchange: four character grid

ARRL September VHF QSO Party: Log Type: ARRLVHFSEP | Exchange: four character grid

CQ WW VHF Contest

  • Log Type: CQWWVHF
  • Sent Exchange: Your four character grid
  • Reverse Call History Lookup feature disponível

Region 1 VHF Contests

Region 1 contesting usa número de série e grid square como exchange. Os pontos por QSO são a distância calculada entre seu grid enviado e o grid recebido.

  • Log Type: VHFREG1
  • Sent Exchange: 001 [gridsquare] (Example: 001 JO33fd)
  • Suporta Call History table com nome e localizadores

International Contests

  • Marconi CW contest: Log Type: VHFREG1 (CW only)
  • NAC Activity Contest: Log Type: VHFNAC
  • VHF/UHF Helvetia 26: Log Type: VHFHELV26 (Swiss VHF contest)
  • VHF UA1DZ Cup: Log Type: VHFDZCUP (Russian contest)
  • VRZA/WANLC: Log Type: REGIOVHF (Dutch contest)
  • YU DX Contest: Log Type: YUDX
  • UKSMG sporadic-E: Log Type: UKSMG (6 meter band)
