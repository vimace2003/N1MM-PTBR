User Defined Contests (UDC)

What is UDC?

User Defined Contests (UDC) permite que você configure contests não-suportados nativamente pelo N1MM Logger+. Você pode definir suas próprias regras de pontuação, multipliers, e parâmetros de troca.

Creating a New UDC

Para criar um novo User Defined Contest:

  • Abra o menu File > New Log in Database
  • Selecione User Defined Contest (UDC) como Log Type
  • Configure os parâmetros do contest seguindo o UDC editor

UDC File Format

Os arquivos UDC são salvos no formato .udc e podem ser compartilhados com outros operadores. Eles definem:

  • Regras de pontuação (pontos por QSO)
  • Multiplicadores (estados, países, zonas, grids, etc.)
  • Formato de exchange
  • Verificação de dupes
  • Bandas permitidas

Using Imported UDC Files

Você pode importar arquivos UDC de outras fontes ou da comunidade N1MM:

  • Coloque o arquivo .udc na pasta UDC do N1MM Logger+
  • O contest aparecerá na lista de contests disponíveis
  • Crie um novo log e selecione-o como você faria com contests nativos

Common UDC Contests

  • Helvetia 70: Swiss VHF contest com multiplicadores de cantões
  • Locator Contest: Contests baseados em grid squares
  • Regional Contests: Contests específicos de regiões locais
  • Multi-mode Contests: Contests com múltiplos modos em um único event

UDC Tips and Tricks

  • Sempre leia as regras completas do contest antes de configurar a UDC
  • Teste a configuração com alguns QSOs de prática antes do contest real
  • Use a opção Rescore para verificar se a pontuação está correta
  • Compartilhe suas UDCs com a comunidade N1MM
