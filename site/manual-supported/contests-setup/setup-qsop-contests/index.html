Setup QSO Parties EN: Setup QSO Parties

Setup QSO Parties – CW and SSB (Setup QSO Parties – CW e SSB)

O programa suporta muitos QSO parties dos EUA e Canadá. Dependendo da complexidade das regras, pode haver anomalias de pontuação menores. Por exemplo, alguns QSO parties oferecem pontos de bônus para rovers ou estações móveis para ativar múltiplos condados; esses pontos de bônus podem não estar incluídos na pontuação calculada pelo programa.

É MUITO importante para operação adequada do programa em QSO parties que o programa "saiba" se você é um participante in-area (estado ou província) ou out-of-area. Todos os QSO parties exigem operação de programa e regras de pontuação diferentes para participantes in-area e out-of-area.

O programa determina isso a partir da ARRL Section que você inseriu no diálogo Station Data (em Config menu). Ao criar um novo log para um QSO party, uma message box informará se o programa pensa que você é um participante in-state ou out-of-state, com base em sua seção ARRL, para que você possa corrigir se houver algo errado.

Estações não-US/VE devem inserir "DX" no campo ARRL SECTION. Se você inserir uma seção ARRL com um call sign não-US/VE, você será avisado para corrigir seus Station Data antes de continuar.

O N1MM Logger+ oferece suporte aprimorado para operações de county-line, seja você o Rover in-state em uma county line ou uma estação out-of-state querendo uma maneira fácil de registrar um QSO com um rover de county line. Detalhes completos estão na seção Mobile/Rover Support abaixo.

  • Janela: Select Log type
    • Log Type: QSOPARTY
      • Após selecionar QSO Party, uma list box aparece na parte direita da caixa de diálogo de seleção de contest, com botões abaixo dela para importar e editar a lista de seções. Clique na seta para baixo para escolher o QSO Party que você deseja (a imagem de exemplo mostra Hawaii HI). Quando em dúvida, faça a importação, para ter certeza de que pega quaisquer mudanças nas abreviações oficiais desde a última execução.
      • Exemplo: A entrada na lista de QSO Parties para o New England QSO Party é "NEWE" ("NE" é para o Nebraska QSO Party). A maioria das entradas nesta lista são estados ou províncias, com exceções que incluem 7QP (7º call area), AC (Atlantic Canada), CP (Canadian Prairies), MAQP (Mid-Atlantic), MARAC (county hunter contest), MCC (Maritimes) e NEWE (New England) assim como a entrada especial IN7QPNE descrita abaixo.
  • Mode Category: MIXED
  • Sent Exchange:
    • O exchange depende do QSO party. A maioria usa county para participantes in-area e state para os out-of-area. Alguns também usam números de série.
    • Dentro do State/Province selecionado — Ver instruções do contest
    • Fora do State/Province selecionado — Ver instruções do contest
    • Se você precisar enviar um número de série, insira 001 e a abreviação para sua localização no campo Sent Exchange, para incrementar automaticamente o número de série para cada QSO.

QSO Party Bonus Station Support (Suporte de Estação Bonus QSO Party)

Alguns QSO parties estaduais têm "estações bonus", que você pode trabalhar para crédito de pontos extras. Quando o state party tem estação(ões) bonus, o programa exibirá a lista de callsign de estação bonus na inicialização do programa e ao sair do diálogo de contest.

Esta lista de estações bonus pode ser modificada pelo usuário inserindo o comando BONUS + Enter na caixa call sign da Entry Window. Isso abrirá uma janela onde você pode inserir uma lista revisada.

Cada call sign, e cada variação (CALL, CALL/M, CALL/CTY) deve estar na lista para obter crédito para a estação(ões) bonus.

Simple Call History Procedure (Procedimento Simples de Call History)

Os passos para gerar um arquivo Call History a partir de um QSO party anterior são os seguintes:

  • Abra o log do contest QSO party do ano passado
  • Clique em Tools, Clear Call History depois Update with Current Log
  • Clique em File, Export Call History e exporte os dados para um arquivo
  • Usando NotePad adicione qualquer estação nova ao final deste arquivo
  • Abra o novo log de contest QSO party para o ano atual. Associar o arquivo de call history salvo com este state party é possível usando a aba Associated Files
  • Clique em Config e coloque uma marca em Call History Lookup

Rover, Mobile, and County Line Support (Suporte Rover, Mobile e County Line)

O N1MM Logger oferece suporte a operação Rover/Mobile e County Line e para contests QSO party, o software contém recursos permitindo à estação home registrar rapidamente a estação County Line.

Rover/Mobile Operation: N1MM logger oferece suporte a operação Rover ou Mobile nos contests VHF ARRL e todos os QSO parties. Dá a um participante Rover uma maneira rápida e fácil de mudar de condados, reprogramar mensagens F-key em um passo e produzir um único log composto para todo o evento.

County Line Operation: A operação de county line é popular com operadores in-state em QSO parties porque você pode dar mais de um designador de county de um único local. Os operadores out-of-state recebem dois ou mais condados — muitas vezes raros — em um único QSO e ganham crédito de multiplicador para cada condado.
