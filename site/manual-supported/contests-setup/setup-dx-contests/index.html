Setup DX, DXpedition e Contests de Propósito Geral EN: Setup DX, DXpedition, and General Purpose Contests

Leia as Instruções do Contest!

Sempre leia as instruções do comitê do contest antes do contest. Então você saberá como configurar o programa, qual exchange fornecer e o que esperar em retorno, quais horas operar, etc.

Generic Contest Types (Tipos de Contest Genéricos)

DX Log (Log DX)

Janela: Select Log type (Selecionar Tipo de Log)

  • Log Type: DX
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Para logging geral ou DX.

  • QSOs inseridos em log geral (ou log DX) não precisam ter um exchange
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado

DXpedition

Janela: Select Log type

  • Log Type: DXPEDITION
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Para logging de DXpedition.

  • QSOs inseridos no log DXPEDITION não precisam ter um exchange
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado
Trabalhando com split VFOs em uma DXpedition — Rx em VFOa, Tx em VFOb

A maioria dos operadores de DXpedition deixará VFOb em uma frequência de transmissão estacionária enquanto sintoniza a pile-up com VFOa em recepção. Para resultados otimizados no N1MM+ execute os seguintes três passos: Defina >Config >Hardware para operação SO2V (Single Op 2 VFO). Coloque o programa e o rádio em modo Split digitando ctrl+S. Desative auto-toggle Run/S&P pressionando alt+F11.

DX Serial (DX Serial)

Janela: Select Log type

  • Log Type: DXSERIAL
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Para logging geral de contests de Número de Série.

  • QSOs inseridos em DXSERIAL não precisam ter um comentário
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado
  • Cálculo de pontos 'Standard'; 1 ponto por QSO, países DXCC são contados
    • Todos os outros tipos de cálculos de multiplicador e pontos têm que ser feitos à mão
    • Isso para todos os contests de número de série não suportados

DX Satellite (DX Satélite)

Janela: Select Log type

  • Log Type: DXSATELLIT
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Para logging de satélite.

  • QSOs inseridos no log DXSATELLIT não têm um exchange e não precisam ter um grid
  • Quando um grid é inserido, ele precisa ter 4 ou 6 caracteres de comprimento
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado

VHF DX (VHF DX)

Janela: Select Log type

  • Log Type: VHFDX
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Para logging de VHF e acima.

  • QSOs inseridos em VHFDX não precisam ter um grid
  • Quando um grid é inserido, ele precisa ter 4 ou 6 caracteres de comprimento
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado
  • Informações de bearing são mostradas na janela de log e salvas no campo Misc
  • Informações de distância são mostradas em km na janela de log e salvas no campo Points

VHF Serial (VHF Serial)

Janela: Select Log type

  • Log Type: VHFSERIAL
  • Mode Category: MIXED se você quer registrar contatos SSB e CW, MIXED+DIG para adicionar modos digitais também

Comentários precisam ser adicionados usando Ctrl+N. Não há espaço deixado na Entry Window para adicionar um campo separado. Comentários serão mostrados na janela de log e adicionados aos relatórios Cabrillo e de saída genéricos.

Para logging de VHF e acima.

  • QSOs inseridos em VHFSERIAL não precisam ter um grid
  • Quando um grid é inserido, ele precisa ter 4 ou 6 caracteres de comprimento
  • Dupes são mostrados pela palavra Dupe! mas o QSO pode ser registrado
  • Informações de bearing são mostradas na janela de log e salvas no campo Misc
  • Informações de distância são mostradas em km na janela de log e salvas no campo Points

Deleted QSOs (QSOs Deletados)

DELETEDQS "contest"

QSOs que são deletados de outros logs usando 'Edit Contact' são movidos para este 'contest'. Isso é especialmente importante para suporte multi-usuário. Os QSOs movidos podem ser exportados.
