Setup Digital Contests

RTTY Contests

N1MM Logger+ oferece suporte completo para contests RTTY. Para contests ARRL e outros, use Mode Category: RTTY. A taxa de baud padrão é 45.45 e a abertura é 170 Hz.

ARRL RTTY Round-Up

  • Log Type: ARRLRTTY
  • Mode Category: RTTY
  • Sent Exchange: RST + Serial Number (001)
  • Dupe check usa call sign + band

CQ WW RTTY Contest

  • Log Type: CQWWRTTY
  • Sent Exchange: RST + CQ Zone
  • Multipliers: DXCC countries + CQ zones

PSK31 Contests

PSK31 é suportado via interface digital. Use Mode Category: DIGITAL quando aplicável.

JT Modes (FT8, FT4, MSK144, etc.)

Modos JT como FT8 e MSK144 são suportados via interface WSJT-to-N1MM+ descrita no manual. Lembre-se de definir Mode category como DIGITAL para habilitar pontuação apropriada.

ARRL EME (Earth-Moon-Earth)

  • Log Type: ARRLEME
  • Exchange: Grid square (4 ou 6 caracteres)
  • Modos digitais disponíveis via interface digital

Digital Mode Interface

Para usar modos digitais avançados, acesse Windows > Digital Interface no N1MM Logger+ e configure a frequência de áudio e os parâmetros de conexão para seu programa de modo digital (como WSJT-X para FT8).
