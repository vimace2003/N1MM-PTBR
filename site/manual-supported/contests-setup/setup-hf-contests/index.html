Setup HF Contests

Major HF Contests

CQWW SSB Contest (CQ Worldwide SSB)

  • Log Type: CQWWSSB
  • Sent Exchange: RST + CQ Zone (Example: 59 05)
  • Multipliers: DXCC Countries + CQ Zones
  • Scored on number of QSOs and multipliers

CQWW CW Contest

  • Log Type: CQWWCW
  • Sent Exchange: RST + CQ Zone
  • Same scoring rules as CQWW SSB

ARRL DX Contest (CW)

  • Log Type: ARRLDXCW
  • Sent Exchange (W/VE): 59 + serial number (001)
  • Sent Exchange (DX): RST + W/VE state
  • Multipliers: W/VE states + DXCC countries

ARRL DX Contest (SSB)

  • Log Type: ARRLDXSSB
  • Same exchange rules as CW version

ARRL Sweepstakes (CW)

  • Log Type: ARRLASS
  • Sent Exchange: Signal Report + Serial + Precedence + Section (Example: 579 001 A MA)
  • Special handling for serial numbers and sections

ARRL Sweepstakes (SSB)

  • Log Type: ARRLASS-SSB
  • Same exchange format as CW version

WPX Contest (CW)

  • Log Type: WPXCW
  • Sent Exchange: 59 + serial number (001)
  • Multipliers: Unique prefixes
  • Dupe checking based on call sign + band

WPX Contest (SSB)

  • Log Type: WPXSSB
  • Same rules as WPX CW

Other Major Contests

  • IARU HF World Championship: IARU
  • All Asian DX Contest: AADX
  • Asian Pacific Sprint: APSPRINT
  • North American QSO Party: NAQP
  • 10-Meter Contest: ARRL10M
  • 160-Meter Contest: ARRL160M
