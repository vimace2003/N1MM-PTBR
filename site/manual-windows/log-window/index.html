Log Window

A Log Window mostra uma tabela de todos os QSOs registrados no contest atual, em ordem cronológica de gravação.

Colunas Disponíveis

  • Call: Indicativo do contato
  • Frequency: Frequência do QSO
  • Mode: Modo (SSB, CW, etc.)
  • Time: Hora UTC do QSO
  • Date: Data do QSO
  • Exchange Sent/Received: Troca enviada e recebida
  • Multiplier: Se é novo multiplicador ou dupe
  • Points: Pontuação do QSO

Edição no Log

  • Clique duplo em um QSO para editar
  • Use Ctrl+D para deletar QSO marcado
  • Rescore automático ao modificar

Filtros e Busca

Use os filtros da Log Window para buscar calls, frequências ou períodos específicos do contest.
