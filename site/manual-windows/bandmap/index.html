Bandmap

O Bandmap é uma visualização gráfica das frequências na banda, mostrando spots de operadores e informações em tempo real durante um contest.

Funcionalidades

  • Spots em Tempo Real: Mostra calls dos operadores recebidos via SDR ou RBN (Reverse Beacon Network)
  • Filtros de Banda: Escolha qual banda exibir
  • Clique para Sintonizar: Clique em um spot para sintonizar o radio naquela frequência
  • Histórico: Mostra contatos anteriores com estações visíveis na banda
  • Dupe Highlighting: Destaca estações já contatadas em vermelho ou cor customizável

SDR Integration

Se você usar uma SDR (Software Defined Radio), o Bandmap pode mostrar spots de frequência baseado em áudio recebido localmente (opcional).

RBN (Reverse Beacon Network)

Integração com RBN permite ver onde seus sinais estão sendo ouvidos mundialmente durante o contest.
