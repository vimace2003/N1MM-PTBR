Check Window

A Check Window exibe informações sobre o call digitado na Entry Window, incluindo histórico de contatos, arquivo master.scp, e verifica dupes.

Informações Exibidas

  • Call History: Contatos anteriores com essa estação
  • Last 10: Últimos 10 contatos gerais no contest
  • Master.scp Match: Confirmação se call existe em banco de dados conhecidos
  • QSO Info: Quando e em qual banda foi o último contato
  • Dupe Indicator: Marca se já existe QSO com essa estação nesta banda

Funcionamento

A Check Window atualiza automaticamente conforme você digita. Use ela para evitar dupes e confirmar informações do operador.

Customização

Você pode customizar cores, fonts e quais informações aparecer via Configurer > Check Window.
