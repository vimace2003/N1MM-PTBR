Entry Window

A Entry Window é a janela principal do N1MM Logger+ para registro de QSOs durante um contest. Ela é o coração da operação.

Campos Principais

  • Call: Indicativo da estação contatada
  • Frequency: Frequência do QSO
  • Mode: Modo (SSB, CW, RTTY, etc.)
  • Exchange: Troca de sinal recebido e informações da contest
  • Time: Hora do QSO (preenchida automaticamente)

Atalhos Essenciais

  • Tab: Move entre campos
  • Enter: Envia QSO (se ESM mode ativo)
  • Ctrl+Z: Desfaz último QSO
  • Backspace: Limpa call e move para próximo campo

Check Window Integration

Conforme você digita o call, a Check Window exibe status: dupe, novidade, história do call, etc.
