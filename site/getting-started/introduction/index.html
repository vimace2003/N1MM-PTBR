O Getting Started (Primeiros Passos) tem como objetivo guiar o novo usuário do N1MM Logger+, ou quem está migrando do N1MM Logger Classic, em ordem cronológica, até o ponto em que ele/ela tenha uma versão do N1MM Logger+ corretamente instalada com funcionalidade básica de log.

PC Requirements (Requisitos de PC)

Minimum Hardware Requirements (Requisitos Mínimos de Hardware)

O N1MM Logger+ incorpora tecnologia multi-thread atual, e aproveita bem CPUs multi-core. É difícil definir uma configuração mínima absoluta que funcione em todas as circunstâncias. Um processador de 4+ núcleos e 3+ GHz é provavelmente o mínimo necessário, mas os requisitos de CPU dependem bastante de quais opções, modos etc. do programa são usados, então isso pode variar conforme o seu uso. O programa em si não exige muita memória, mas quanto mais memória você tiver, mais suave fica a multitarefa do Windows. A memória é especialmente importante quando a CPU é de núcleo único. Se você gastou mais de US$ 3000 na sua estação, considere gastar um pouco mais para ter um PC melhor.

A resolução gráfica mínima recomendada é 1024 por 768 (SVGA), ou 1366 x 768 (720p) para monitores widescreen, com muitos hams usando resoluções maiores e telas duplas. Em resoluções verticais menores que 768 pixels, como em muitos netbooks, várias das janelas maiores não cabem inteiramente na tela.

O controle de rádio pode ser feito por portas seriais ou por um adaptador USB-serial. Chaveamento de CW, FSK RTTY e PTT podem ser feitos por portas seriais ou paralelas, por um adaptador USB-serial, ou pelo Winkeyer da K1EL (uma excelente solução que tira todo o processamento de CW do computador). Para FSK RTTY, é necessária uma porta serial extra. Para AFSK, PSK31 e outros modos que exigem interfaceamento de áudio, os mesmos métodos descritos para interfaceamento de fonia podem ser aplicados.

Caixas de SO2R podem ser controladas por uma porta LPT de hardware, tanto em sistemas operacionais de 32 quanto de 64 bits. Alternativamente, tanto o MicroHam USB SO2R Control Protocol quanto o K1XM Open Two Radio Support Protocol são suportados, para uso com dispositivos compatíveis.

Conversores USB-serial e dispositivos de interface USB são suportados por meio de portas seriais virtuais fornecidas pelo respectivo driver. Conversores USB-LPT não podem ser usados nem para controle de SO2R nem para funções de CW/PTT, exceto o PIEXX SO2RXLAT (projetado especificamente para esse fim).

Para mais informações, veja a seção Interfacing.

Supported Operating Systems (Sistemas Operacionais Suportados)

  • Windows 11 32/64 — preferencial
  • Windows 10 32/64 — preferencial
  • Windows 8.1 32/64
  • Windows 7 32/64 — suporte da Microsoft encerrado em 14/01/2020. Não recomendado. Pode ser necessário instalar o .Net 4.6.2 para o N1MM funcionar
  • Windows Vista 32/64 — não recomendado
  • Windows XP SP3 — suporte encerrado em 31/01/2021. Versões lançadas após essa data não funcionam no XP. Nenhuma correção será feita para a última versão compatível com XP

Linux e outros sistemas operacionais não têm suporte nativo. O OM2LT fez um ótimo trabalho documentando como rodar o N1MM+ no Linux usando o Wine. Veja Contesting with N1MM on Linux (em inglês).

Erros de inicialização no Windows XP e Vista

Se você ainda usa Windows XP ou Vista, pode ver mensagens de erro ("erro 404" ou "não foi possível conectar ao servidor") toda vez que inicia o programa. Essas mensagens aparecem porque você está usando um sistema operacional que não suporta a segurança web atual. A Microsoft não fornece suporte a criptografia SSL para sites modernos no XP e Vista, então a conexão https com o site do N1MM+ para checar atualizações não funciona. Se o seu navegador foi atualizado para permitir conexão a sites modernos, você consegue baixar a atualização mais recente pelo navegador e atualizar o programa manualmente, mas a checagem automática de versão feita pelo programa na inicialização continuará falhando.

Sistemas operacionais sem suporte ficam mais vulneráveis a ataques de malware, porque os autores de malware sabem que as vulnerabilidades encontradas não serão corrigidas. Isso deixa seu sistema potencialmente aberto para ser usado por malware como um bot, atacando outros sistemas. Faça um favor a você mesmo e a todo mundo: atualize para um sistema operacional com suporte.
