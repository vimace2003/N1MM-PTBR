Full Installer (Instalador Completo)

Instalar o N1MM Logger+ pela primeira vez exige baixar dois arquivos — o Full Installer (Instalador Completo) e o Latest Update (Última Atualização). O arquivo Full Installer muda com pouca frequência, enquanto o Latest Update muda com frequência, geralmente uma vez por semana.

Encontre o arquivo Full Installer no site de downloads, no menu >Downloads >Program Files >Full Install Info >Full Install File. Salve o arquivo, chamado N1MM Logger+ FullInstaller [número da versão].exe, na sua pasta de downloads ou na área de trabalho do seu PC.

Você só precisa fazer um Full Install!

Full Installers não são publicados com frequência. Se a primeira parte do número de versão atual (a parte antes do segundo ponto) for igual à da sua cópia já instalada do programa, você NÃO precisa rodar um novo Full Installer. Para atualizar o programa, basta baixar e instalar o Latest Update.

Latest Update (Última Atualização)

Encontre o arquivo Latest Update no site de downloads, no menu >Downloads >Program Files >Latest Update Info >Latest Update Files. Procure o arquivo mais recente (o de maior número de versão — você pode clicar no cabeçalho da coluna Name para inverter a ordem, ou no cabeçalho da coluna Modified para organizar por data, clicando duas vezes se necessário para colocar o mais recente no topo). Salve o arquivo no mesmo local onde salvou o Full Install. (Exceção: se o número de versão do Full Install for igual ao do Latest Update, não é necessário instalar o Latest Update por cima.)

Você só precisa de um arquivo Latest Update!

Cada arquivo Latest Update inclui as melhorias e correções de todos os arquivos anteriores. Só é necessário baixar e instalar um Latest Update — geralmente o mais recente — para deixar o N1MM Logger totalmente atualizado.

Convenção de Nomes dos Arquivos Latest Update

A sintaxe de nomes dos arquivos Latest Update é N1MM Logger+ Update [número da versão].exe. O número de versão segue o formato x.yy.zzzz, onde x é o número de revisão principal (muda raramente), yy é o número de versão principal (também muda raramente), e zzzz é o número de versão menor (muda a cada versão). Mudanças no número yy indicam alteração nos arquivos de sistema necessários para o programa. Instaladores de update cujo yy for diferente do yy da versão instalada não vão instalar por cima da versão existente. Por isso, sempre que o yy mudar, você vai precisar baixar um novo Full Installer com o novo yy e refazer o Full Install antes de atualizar. Por outro lado, se o yy do Full Installer atual for igual ao da sua cópia já instalada, você não precisa fazer um novo Full Install; basta baixar e rodar o instalador de update mais recente. O número de versão menor zzzz muda toda vez que algum membro da equipe de desenvolvimento altera o programa. Nem toda mudança gera um novo instalador de update; por isso pode haver lacunas nos números zzzz. Isso não é um problema; a menos que haja um motivo específico para voltar a uma versão mais antiga, basta instalar o update mais recente (o de maior número zzzz).
